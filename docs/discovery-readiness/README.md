# EXONYM discovery readiness assessment

This target-neutral assessment compares EXONYM's independent TESS discovery goal with public NASA, TESS, MAST, and community validation practice.

Build the site from this directory:

```powershell
uvx zensical build
uvx zensical serve -o
```

The assessment does not contain candidate identities, measurements, or research payloads. Those remain in `candidate/`.
