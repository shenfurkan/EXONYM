# Paper templates

`paper_template.tex` is a target-neutral discovery-manuscript scaffold. `exonym init` copies it into each candidate's `paper/` directory, and `exonym export-paper <candidate-id>` writes candidate-owned macros to `paper/generated/exonym_macros.tex`.

The template labels unavailable evidence rather than creating values. It does not turn a screening artifact, FPP estimate, or workflow phase into a discovery claim.
